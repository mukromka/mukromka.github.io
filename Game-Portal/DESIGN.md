# Prompt Handoff Desain Website — Premium Chinese AI Models

## 1. Tujuan Dokumen

Dokumen ini adalah **prompt + design specification** untuk di-handoff ke AI lain agar bisa mendesain website bertema **Chinese AI Models** dengan nuansa **premium, elegan, modern, minimal, dan profesional**.

Desain harus **terinspirasi dari style visual referensi saat ini**, tetapi **dibersihkan total dari kesan judol / gambling / promo murahan / game / marketplace banner**.

Fokus utama:

* menampilkan kesan **premium AI service**
* menonjolkan model:

  * **DeepSeek**
  * **GLM**
  * **Qwen**
  * **Kimi**
* visual harus terasa:

  * modern
  * refined
  * premium
  * clean
  * Chinese-inspired but subtle
  * high-end SaaS / AI platform
* **bukan** poster promosi, **bukan** banner diskon, **bukan** judol, **bukan** game UI

## 5. Typography

### Arah Tipografi

Gabungkan:

* **elegant serif** untuk headline utama
* **modern sans-serif** untuk body text, UI labels, dan navigasi

### Rekomendasi Pairing

**Headline serif:**

* Cormorant Garamond
* Playfair Display
* Noto Serif SC (jika ingin nuansa Chinese-inspired lebih halus)
* DM Serif Display

**Body / UI sans-serif:**

* Inter
* Manrope
* Plus Jakarta Sans
* SF Pro / system sans-serif
* Noto Sans

### Aturan Tipografi

* Headline besar: refined, lapang, elegan
* Body copy: clean, ringan, mudah dibaca
* Letter spacing pada judul bisa sedikit diperlebar
* Gunakan hierarchy yang jelas:

  * H1 besar dan dominan
  * H2 tegas
  * paragraph ringan dan pendek
* Hindari font display yang terlalu dekoratif
* Hindari all caps berlebihan kecuali untuk small label tertentu

### Karakter Tipografi yang Diinginkan

* airy
* high-end
* premium editorial
* clean
* confident
* not loud

## 10. Animation & Motion Direction

Animasi harus terasa:

* smooth
* subtle
* refined
* modern
* premium
* bukan flashy

### Prinsip Motion

* durasi pendek-menengah
* easing halus
* tidak ada bounce berlebihan
* tidak ada blink / flashing
* tidak ada motion berisik

### Animasi yang Direkomendasikan

#### A. Page Load Animation

* hero content fade in + slight upward motion
* staggered reveal pada model cards
* decorative lines muncul perlahan
* background pattern softly fade in

#### B. Hover Animation untuk Cards

* card naik sedikit (`translateY(-4px)` atau `-6px`)
* shadow sedikit bertambah
* border / accent glow sangat halus
* icon scale sedikit (`1.02`–`1.05`)

#### C. Button Animation

* smooth color transition
* subtle shadow shift
* light shimmer atau highlight slide yang halus
* tidak boleh terlalu glossy

#### D. Section Reveal on Scroll

* fade up
* small parallax sangat halus
* reveal per blok konten
* gunakan stagger ringan untuk daftar card

#### E. Decorative Motion

* cloud line drifting sangat halus
* gold line shimmer tipis
* background motif static atau sangat minimal
* bamboo silhouette tidak perlu bergerak banyak

### Animation yang Harus Dihindari

* slot-like spin
* coin rain
* pulsing besar
* flashing neon
* jackpot style transitions
* scrolling text norak
* bouncing price tags
* confetti

## 18. Master Prompt Siap Copy-Paste ke AI Lain

```md
Design a premium, elegant, modern website landing page for a platform that offers Chinese AI models, specifically DeepSeek, GLM, Qwen, and Kimi.

The visual style should be inspired by refined Chinese aesthetics, but in a subtle and sophisticated way. The website must feel like a high-end AI SaaS product, not a marketplace banner, not a sales poster, and absolutely not like gambling, casino, or flashy promotional material.

Style direction:
- premium
- elegant
- minimal luxury
- editorial tech aesthetic
- modern Chinese-inspired design
- clean layout
- refined typography
- soft shadows
- thin gold details
- warm ivory background
- subtle deep red accents
- understated oriental motifs

The design should use a warm, light, premium base:
- ivory / warm white backgrounds
- soft beige secondary surfaces
- deep Chinese red accents
- antique gold decorative lines and borders
- dark charcoal text
- muted gray supporting text

Use typography pairing:
- elegant serif for hero headlines
- modern sans-serif for body text, navigation, UI labels, and buttons

Create a website with:
1. Hero section
2. Model showcase cards for DeepSeek, GLM, Qwen, and Kimi
3. Feature / benefits section
4. Pricing or value proposition section
5. CTA section
6. Footer

Model cards should be clean and premium:
- light ivory card backgrounds
- subtle border
- soft shadow
- rounded corners
- consistent spacing
- each card contains icon/logo, model name, and short supporting text

Use subtle Chinese-inspired decorative elements only:
- fine cloud line motifs
- soft scallop wave patterns in the background
- very subtle bamboo silhouette
- thin gold dividers
- geometric oriental ornaments
Do not make ornaments dominant.

The page should feel spacious, calm, trustworthy, and high-end.

Avoid:
- flashy gradients
- loud red-gold combinations
- 3D promo banner style
- big badges
- price tags
- market-sale visuals
- slot machine feeling
- casino / gambling aesthetics
- jackpot style effects
- crowded composition
- excessive glow
- cartoonish visuals

Motion and animation direction:
- smooth and subtle
- fade-in on load
- slight upward reveal on sections
- staggered card reveal
- elegant hover lift on cards
- soft shadow increase on hover
- subtle button transition
- no flashy motion, no bounce-heavy effects, no blinking elements

The final result should look like a premium AI product website with subtle Chinese identity, strong visual hierarchy, a refined luxury-tech feel, and a clean user experience.

Also provide:
- desktop, tablet, and mobile responsive versions
- component states
- hover states
- motion guidance
- mini style guide
```
