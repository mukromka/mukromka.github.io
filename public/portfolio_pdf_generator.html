Artwork/Project Description
In this project, I worked on improving Bos Gabut as a mobile quiz-and-reward platform where users can earn prizes through daily mini-game challenges. My main responsibility was leading the UI/UX overhaul for the event features and game flows, so the experience felt clearer, faster, and more engaging for daily users. I also redesigned the landing pages and added an SEO-driven blog to support organic growth. This project helped me connect design decisions with product goals such as retention, DAU, and user sign-ups while shipping iterations in a live product environment.

Artwork/Project Description
Moon Flower was one of the projects that taught me a lot about long-term creative discipline. As part of the team, I helped develop the story arcs, write scripts and dialogue, and maintain consistent base colouring across 60 episodes and 2 seasons. The comic was published on LINE Webtoon Indonesia and reached more than 13.4M reads, 270K favorites, and a 9.76/10 rating. Working on a weekly release schedule pushed me to manage time carefully, communicate clearly with the team, and keep the visual quality consistent over a two-year production cycle.

Mie Ayam Simulator
Year Accomplished
2023
Role/Position
2D Artist & UI/UX Designer - Group Project
Publication Link
https://play.google.com/store/apps/details?id=com.EverStudio.MieAyamSimulator
Artwork/Project Description
For Mie Ayam Simulator, I helped shape both the visual identity and the player interface for a casual simulation game about running an Indonesian street-food stall. I designed the in-game HUD, main menu flow, and shop interface with one-handed mobile play in mind, while also creating character sprites, food illustrations, and environment assets. Since the game reached more than 80K downloads on Google Play, I learned how important it is to make the interface easy to understand while keeping the art direction culturally familiar and appealing to local players.
